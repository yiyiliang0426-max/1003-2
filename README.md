# 一起好好相處｜性別教育互動練習

這是一個單頁、免安裝的繁體中文互動網頁，提供不同學習需要的大學生進行易讀性別教育練習。

## 活動內容

- 認識情緒與自我調節
- 友善對話、人際關係與交友方法
- 身體界線、同意與拒絕
- 性別尊重、衝突處理與求助
- 交友 APP 紅黃綠燈、約會安全
- 保險套、安全性行為及性傳染病防治

## 本機使用

下載 `index.html` 後，以 Chrome、Edge 或其他瀏覽器開啟即可。互動練習在本機執行，不會將作答送到伺服器。

## 部署

此專案是靜態網頁，可直接部署到 Vercel，無需建置指令或環境變數。

## 健康資訊提醒

本頁提供一般教育資訊，不是診斷或個人醫療建議。正式教學前，請邀請性平、特教及醫療／公共衛生專業人員審閱，並補上適用學校的求助聯絡方式。
